❓ Часто задаваемые вопросы

В: Как быстро приходят алерты?
О: В течение 30-60 минут после публикации (система проверяет источники каждый час)
В: Включена ли веб-панель в MVP?
О: Нет, в MVP только Slack-алерты. Веб-панель — опциональная фаза 2 (+$600) для анализа исторических данных. Подробности на странице Реализация.
В: Можно ли отменить подписку?
О: Да, контракт только ежемесячный. Вы можете отменить в любой момент и получить полный экспорт всех данных в CSV/JSON.
В: Почему CloudMax $100?
О: CloudMax подписка нужна только при разработке (2 недели), чтобы не упираться в лимиты токенов Claude. После запуска система переходит на прямой API Anthropic с Prompt Caching для 40-50% экономии. Подробности в разделе Реализация.

Полный контроль за вашими данными

Система предоставляет вам полный доступ к управлению данными о конкурентах:

  • Веб-панель: Полный интерфейс для просмотра, поиска и анализа всех собранных алертов
  • Экспорт данных: Возможность выгружать данные в CSV/JSON для анализа в собственных инструментах
  • Управление мониторингом: Вы можете добавлять/удалять конкурентов, изменять источники, настраивать правила алертов
  • Резервные копии: Полный доступ к истории данных — ничего не теряется
  • Интеграции: При необходимости мы можем подключить дополнительные каналы (email, Telegram и т.д.)

Ежемесячная поддержка () включает техническую помощь в управлении системой и optimизации под ваши процессы.

❓ Вопросы о стоимости

В: Почему CloudMax $100 на разработку?
О: CloudMax подписка нужна только при разработке, чтобы не упираться в лимиты токенов Claude и уложиться в 2-недельные сроки без ограничений.

После запуска: Система переходит на Direct API Anthropic (прямой аккаунт), где включено автоматическое Prompt Caching на уровне кода. Это даёт 40–50% экономию на токенах и позволяет держать цену на уровне /месяц.
В: Что такое токены Claude и почему они дорогие?
О: Токены — это единица обработки. 1 токен ≈ 4 символа. Каждый алерт требует ~1,700 токенов input/output (~7-8 млн/месяц при 100-150 алертов/день). Цена: Input $3/млн, Output $15/млн. Оптимизируется через Prompt Caching (~40% экономия). Подробно в разделе выше.
В: Почему Render.com дешевле?
О: Потому что PostgreSQL БД включена в плане хостинга. Не нужно платить отдельно $25/месяц за управляемую БД.
В: Могут ли расходы расти?
О: До определённого лимита — нет. /месяц включает обработку алертов при нормальной активности конкурентов (100–150 алертов/день, ~7–8 млн токенов).

⚠️ Исключение: При аномальном всплеске активности (крупное событие в индустрии, новый рынок, кризис), если система обработает 500+ алертов в день, может произойти превышение лимита токенов. В этом случае дополнительные токены биллируются по факту использования (Input $3/млн, Output $15/млн).

Защита: С включённым Prompt Caching (40–50% экономия) превышение маловероятно даже при 2x росте объёма.
В: Можно ли оптимизировать расходы?
О: После запуска можно переойти на Claude Haiku если качество анализа будет достаточным, но мы рекомендуем начать с Sonnet.

✅ Почему эта цена справедлива

Важный момент: Это не просто сбор новостей (как обычный RSS-агрегатор). Это аналитическая система. Аналитик тратит 80% времени на чтение мусора из RSS лент. Наша система фильтрует, анализирует и подает готовую «выжимку» — структурированный алерт с контекстом, чем это важно и что делать.
