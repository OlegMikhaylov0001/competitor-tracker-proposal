Claude 3.5 Sonnet API - расчет токенов

Понимание стоимости Claude обработки

📊 Что такое токены?

1 токен ≈ 4 символа текста. Claude API считает токены для input и output

🔍 Процесс обработки алерта:

• Получаем статью (~500-1000 слов) = ~300-500 токенов
• Отправляем Claude на анализ = ~500 токенов input
• Получаем рекомендации = ~200 токенов output
• ИТОГО на алерт: ~700 токенов

📈 Ежедневные расходы:

100-150 алертов/день × 700 токенов = 70,000-105,000 токенов/день

💰 Claude 3.5 Sonnet цена:

• Input токены: $3 за 1 млн
• Output токены: $15 за 1 млн
• Результат: ~$80-90/месяц для 100-150 алертов/день

✅ Почему 3.5 Sonnet?

• Отличное качество анализа
• Оптимальная цена (в 10+ раз дешевле Opus)
• Доставка алертов в течение 30-60 минут
• Хорошо понимает контекст и стратегию

❓ Вопросы о стоимости

В: Почему CloudMax $100?
О: CloudMax подписка нужна только при разработке, чтобы не упираться в лимиты токенов Claude и уложиться в 2-недельные сроки без ограничений.
В: Что такое токены Claude?
О: Токены — это единица обработки. 1 токен ≈ 4 символа. За каждый запрос к Claude платим за input и output токены. Смотрите раздел выше для полного объяснения.
В: Почему Render.com дешевле?
О: Потому что PostgreSQL БД включена в плане хостинга. Не нужно платить отдельно $25/месяц за управляемую БД.
В: Могут ли расходы расти?
О: Нет. $119/месяц — это фиксированная ставка. Даже если алертов будет больше, стоимость не меняется (Claude платит за использованные токены, которые уже в бюджет заложены).
В: Можно ли оптимизировать расходы?
О: После запуска можно переойти на Claude Haiku если качество анализа будет достаточным, но мы рекомендуем начать с Sonnet.
