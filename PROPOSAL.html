🏗️ Архитектура системы

Слой 1: Источники новостей
50+ новостных сайтов (TechCrunch, Reuters, Bloomberg, локальные издания)

Слой 2: RSS мониторинг
Система проверяет ленты каждые 30 минут, отслеживает новые публикации

Слой 3: Claude 3.5 Sonnet анализ
• Определяет конкурента из списка
• Определяет тип события (8 категорий)
• Оценивает приоритет (1-5)
• Генерирует рекомендации

Слой 4: PostgreSQL База данных (на Render.com)
Хранит все алерты с историей, индексирует для поиска

Слой 5: Вывод в Slack
Отправляет структурированные уведомления в реальном времени

🤖 Технология: Claude 3.5 Sonnet

Почему Claude 3.5 Sonnet?
• Отличное качество анализа за оптимальную цену
• Быстрая обработка (2-5 минут на алерт)
• Хорошо понимает стратегический контекст рынков
• Генерирует качественные рекомендации
• $81/месяц за 100-150 алертов/день

Как считаются расходы?
Каждый алерт требует обработки ~700 токенов (input + output). При 100-150 алертах/день это ~$80-90/месяц Claude API.

🌐 Инфраструктура: Render.com

Почему Render.com?
• PostgreSQL БД включена в план хостинга (экономия $25/месяц)
• Простая развёртка Node.js приложения
• Автоматическое восстановление при сбое
• Git интеграция (автоматическое обновление при push)
• Встроенные логи, метрики, мониторинг
• 99.9% uptime гарантия
• Total: $12/месяц (вместо $20+ на других платформах)
